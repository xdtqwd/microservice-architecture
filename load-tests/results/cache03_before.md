# CACHE-03 — без singleflight (теоретический сценарий)

Без singleflight: все N горутин получают cache miss одновременно
и идут в PostgreSQL за одной строкой.

Реальный замер невозможен без изменения кода — нужен отдельный
тестовый стенд без singleflight.

Ожидаемое поведение: при 100 VU и TTL=5s ~100 DB вызовов на каждый промах.
