# CACHE-03 — без singleflight (теоретический замер)

**Сценарий:** TTL = 5s, 100 VU, момент протухания кэша

При истечении TTL все 100 горутин получают cache miss одновременно
и идут в PostgreSQL за одной строкой.

| Метрика | Значение |
|---------|----------|
| DB запросов при stampede | ~100 одновременно |
| Всплески каждые | 5 секунд (TTL) |
| За 30 секунд всплесков | ~6 |

## Проблема
100 одинаковых запросов к БД за одну строку вместо одного.
