# Миграции

## Источник правды: migrations/goose/

Накатываются автоматически через сервис `migrate` в docker-compose.
Повторный запуск безопасен — goose отслеживает применённые версии.

## Остальные файлы

- `init.sql` — справочник, НЕ используется для инициализации
- `seed_big.sql` — данные для нагрузочных тестов, запускать вручную
- `indexes.sql` — дополнительные индексы для нагрузочных тестов
